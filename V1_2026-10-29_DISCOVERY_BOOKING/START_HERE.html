Start here

In this folder, double-click START_VIRSAPUR.cmd. It starts Virsapur on your computer and opens the website. The first start can take about a minute. Then use these links:

  • Local Production — latest website420 archive articles · all 606 heritage places · 12 sample activities with booking and tickets. Real Draft/Review content remains included for private review.
  • Development PreviewWorking content plus labelled demo fixtures. Studio saves appear here.
  • Admin StudioLocal content, photographs, programmes, quotes and mock orders.
  • Experiences & Programmes
  • Custom itinerary builder
  • Booking, payment & sample tickets

Opening individual website HTML files directly will not run all interactive features. Use the launcher and the links above.

For your developer

site/ contains the complete source, content and geography. site/dist-production/ is the local review website; site/dist-demo/ is development Preview; site/studio/ is Admin source. The bundled Windows runtime lets this package run without installing Node.

See README and package manifest. The older October 22 release candidate is preserved separately.

To stop this package, double-click STOP_VIRSAPUR.cmd.
