Depar Ghanghro Stupa

Heritage Site

Sanghar · Sindh

At Depar Ghanghro near Jhol, an archaeological mound preserves the remains of a stupa built with both fired and unfired bricks. The official record identifies it with Sindh’s Buddhist-period archaeology.
