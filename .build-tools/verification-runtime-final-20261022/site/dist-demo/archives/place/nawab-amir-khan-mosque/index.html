Nawab Amir Khan Mosque

Heritage Site

Thatta · Sindh

Nawab Amir Khan mosque is a small, square-plan brick structure in Thatta with a domed prayer chamber. Its documented Mughal-period form survives in a different location from the Shah Jahan Mosque.
